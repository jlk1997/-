# 安装比特音创作者连接器

给个人代发用户。厂牌用户不用装。

1. Chrome 打开 `chrome://extensions`，打开开发者模式。
2. 加载已解压扩展：选 `apps/creator-connector`。或运行 `npm run pack:connector`，解压 `dist/bityin-connector.zip` 再加载。商店上架后改从 Chrome / Edge 商店安装，见 `STORE_LISTING.md`。
3. 创作者中心 → 账户 →「发送到已安装的扩展」。找不到扩展时会复制 `BITTUNE_PAIR` 文本，再在弹层点「从剪贴板配对」。重新发送会作废旧令牌，扩展以服务器账期和上次收割为准。
4. 打开已登录的音乐人后台，点「把当前后台交给比特音」。
5. Chrome 开着时，扩展按席位任务进对账页：等表格出现 → 优先读官方 CSV → 翻页合并 → `POST /seats/harvest`。
6. 点「打开工作台」盯实时进度。店后台页底部会出提示条。收割成功或登录墙都会通知。

会话过期会角标 `!`。收割中角标 `…`。关浏览器不会继续抄你的号。微信请复制 H5 到电脑完成一次连接。
