安装比特音创作者连接器

给个人代发用户：授权你自己已经登录的店后台。厂牌用户不用装，平台席位由农场收割。

  1. 打开 Chrome，地址栏输入 chrome://extensions。
  2. 打开右上角「开发者模式」。
  3. 点「加载已解压的扩展程序」，选仓库里的 apps/creator-connector；或先运行 npm run pack:connector，解压 zip 再加载那个文件夹。
  4. 回到比特音创作者中心 → 账户，点「发送到已安装的扩展」。扩展图标会提示已配对。
  5. 打开已登录的网易 / QQ / Spotify 等音乐人后台，点扩展里的「把当前后台交给比特音」。

装好后会打开工作台。Chrome 开着时才会自动进对账页、优先读官方 CSV。关掉浏览器不会继续抄你的私号。扩展不填密码、不点发布、也不假装官方 API。收割成功、登录墙、对账表读不到都会通知。
