# 分发授权与分成协议

**生效日期：2026-09-02**  
**版本号：2026-09-02**

本协议由你与比特音运营方订立，适用于将 AI 生成作品通过平台席位或你本人授权的音乐人账号发行到流媒体平台。

## 一、两种模式

1. **个人代发（self_release）**：作品版权归你。你使用自己的音乐人后台或分发商账号上架。授权席位后，平台收割你的后台对账，抽 10% 服务费，净额进入法币钱包。不授权席位则钱不经平台。
2. **平台厂牌分成（label）**：你授权平台以厂牌席位交歌并收割各店音乐人后台。默认抽 20%；你名下前三首在架厂牌作品促销 10%。已签署 10% / 20% / 30% 档位的，按已签档位。净额进入法币钱包。

合作方 DistroKid / TuneCore 等官方接口仅为占位，不是结算来源。

## 二、数据与结算

厂牌赚钱主路是经你授权的席位收割（平台席位或自己席位）。对上曲目的收割行当天或次日可结算入账，不用等 T+45 官方对账单。

官方 CSV / 合作 API 是运营旁路，不能盖掉同一曲目、渠道、账期已入账的席位收割。未匹配收割行进入运营未归属队列，不进任何创作者钱包。账户合计行按已对上曲目的播放份额拆分；拆不开的仍留在未归属队列。

同一笔收割入账再按分成表拆开，最多 4 人且合计必须 100%。后续收割上调只结增量；下调按同一抽成档位冲回各分成方。

积分打赏与法币版税永不加总。电台预热是站内科目，不是商店版税。

## 三、提现

可提现余额需达到最低额度。国内支持微信、支付宝、银行卡；海外支持 PayPal / Stripe。提现必须绑定本人收款账户并通过实名审核。财务打款后再标已付。周五任务不会自动汇出。

## 四、AI 标识

发行作品须保留 AI 生成披露，不得删除平台或分发商要求的标识。

## 五、创作者连接器

连接器是你的钥匙，不是我们的爬虫。只在你已登录的官方音乐人后台、你勾选并点过「同步」的范围内读取可见数据。我们不保存你的店密码，不替你解验证码，不承诺 Spotify 等未提供官方 API 的后台长期可自动同步。

默认同步播放、曲目和地区，并给出预计收入区间，供你对照各店。预计收入不是结算、不能提现；实际金额以各店官方对账单为准。把同步行用于结算入账（个人代发抽 10%）必须另行勾选授权，并已签署本协议。你可随时撤回结算/上传范围而不必断开整店。

DOM 读取仅在你主动点同步时发生。优先使用各店官方导出 CSV 或未来官方 API。
