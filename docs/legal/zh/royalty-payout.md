# 分成说明与提现须知

**生效日期：2026-09-02**  
**版本号：2026-09-02**

1. 厂牌席位默认抽 20%，前三首在架厂牌作品促销 10%；自己席位抽 10% 服务费。已签署档位的按已签档位。同一收割账期的上调与冲回锁定首次入账档位。
2. 可结算余额来自席位收割对上的曲目，不是官方 T+45 对账单。确认后转入可提现。未匹配行进入运营未归属队列，不进任何创作者钱包。低置信或未达自动确认门槛的收割保持待运营确认，不会直接进入可提现。
3. 提现必须绑定本人收款账户，并通过实名审核。财务打款后才会标已付。周五任务不会自动汇出。
4. 请如实填写收款账户。跨境提现可能产生通道手续费与税务申报义务，由你自行承担。
5. 积分打赏不能提现，也不进入法币钱包。
6. 创作者中心展示的预计收入是区间估算，不是可提现余额。连接器默认同步不入账。
