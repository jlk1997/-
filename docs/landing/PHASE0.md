# 第 0 阶段：先定下来的事

这些事不靠再写一段自动填表就能解决。工程按这里执行。

## 厂牌账号

默认上传走平台自己的厂牌或发行账号，分成 20%。用户愿意时，改用他自己的音乐人账号，分成 10%。

每家店要单独办入驻。办下来之前，这一家不能承诺代传。密码放在密钥库，不进业务表，后台只显示有没有凭证。

要办的店：网易云、QQ 音乐、酷狗、酷我、汽水、B 站、抖音、快手、视频号。海外店等有正式接口再办，不先用网页代填。

状态记在运营后台「厂牌账号」里。现在都还没办。

## 用户自己账号上的 10% 怎么收

钱进的是用户自己的平台账户，我们扣不下来。

已经定的做法：10% 写在分发许可上，财务按月对账收取。不从用户的店铺账户划款，也不做成自动扣款。

以后如果平台厂牌已经代收了这个人的其他收入，可以改成从那笔里抵。再以后也可以改成固定服务费。这两条先不启用。

## 各店要填什么

总字段和每家必填项在 `backend/app/services/distribution/channel_fields.py`。

这是初稿。运营要打开每家现在的上传页，逐项核对，核对完才把状态从「待核对」改成可用。核对完成之前，缺这些字段会提示，但不拦住提交。

## 谁在后台看什么

- 发行运营：待上传、发行单、厂牌账号、自动化成绩。
- 财务：结算、提现、每个用户的余额能不能对上。
- 内容审核：用户和举报。
- 管理员：以上全部，以及审计日志。

平台管理员账号仍然什么都能做。
